Nexus · Phone camera setup

This HTTP page is a setup guide only. Mobile camera access requires trusted HTTPS; the desktop app provides a private local certificate.

  1. Download this PC's certificate
  2. Android Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate. Select nexus-phone-root.crt. Menu names vary by Android version; a device lock/PIN may be required.
  3. Restart Chrome, then open the HTTPS camera link below. If Chrome still reports an untrusted site, check the phone date/time, confirm the certificate was installed as a CA, and use the same PC IP. Do not disable browser security globally.

Connection trouble?

  • PC and phone must share the same Wi-Fi. Guest networks can block peer-to-peer access.
  • Allow Nexus in Windows Firewall for Private networks; no administrator privileges are required to run the app, but managed firewall changes may require your IT administrator.
  • The configured port is for this guide; the next port is the HTTPS camera page. WebRTC also uses local ephemeral UDP ports.
  • Disable VPN routing if the displayed PC address is not your Wi-Fi address, or set the address in Settings → Phone.
No cloud signaling, external JavaScript, or internet connection is used for video.
